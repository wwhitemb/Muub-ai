# 工作簿布局与视觉规范

## 数据层级

推荐使用以下层级表达系统关系：

```text
主控芯片
└── 接口方向
    └── 接口分类
        └── 具体功能
            └── 芯片引脚号 / 芯片 IO / 原理图网络
```

每一层都应能回溯到来源。芯片手册提供的复用功能、原理图读到的网络名、项目分配的实际功能和需求表中的功能项分别保存在独立字段。

## 工作表字段

### 系统IO总览

建议字段：主控芯片、接口方向、接口分类、具体功能、芯片引脚号、芯片 IO/复用、原理图网络、功能说明、需求状态、备注。

### 芯片引脚表

建议字段：引脚号、引脚名称、类型、I/O 电平、主功能、默认复用功能、重定义功能、原理图网络、实际功能、需求对应、连接状态、备注。

### 外设汇总

建议字段：外设/接口、方向、接口分类、具体功能、使用引脚、原理图网络、需求项、实现状态、备注。

### 需求对应

建议字段：需求编号、需求描述、接口/外设、具体功能、对应 IO、实现状态、验证状态、备注。

## 颜色方案

颜色需要按功能组固定。可以使用以下低饱和底色作为起点，并根据工作簿可读性调整明度：

| 功能组 | 建议颜色 | 使用范围 |
| --- | --- | --- |
| 电源/地 | 浅橙色 | 电源输入、地、稳压和供电监测 |
| 显示数据 | 青绿色 | LCD/RGB/并行或串行显示数据 |
| 显示控制 | 浅绿色 | 片选、复位、背光、同步和控制信号 |
| 模拟采样 | 浅黄绿色 | 电压、电流、温度和传感器模拟量 |
| 按键/控制 | 浅橙黄色 | 按键、开关、使能和控制输入 |
| CAN 通信 | 浅蓝色 | CAN 收发器和 CAN 总线信号 |
| UART/串口 | 浅天蓝色 | 调试、蓝牙、无线模块和串口通信 |
| SPI/I2C | 浅紫色 | SPI、I2C 和其他串行总线 |
| 存储 | 浅黄色 | NOR Flash、EEPROM、TF/SD 等 |
| 灯光/蜂鸣器 | 浅红色 | 指示灯、背光驱动和蜂鸣器 |
| 下载调试 | 淡紫色 | SWD、JTAG、下载和调试接口 |
| 时钟/复位 | 浅青色 | 外部时钟、晶振、复位和启动节点 |
| NC/未连接 | 浅灰色 | 未连接、保留和无效复用 |
| 其他复用 | 中性灰色 | 已读取但未归入主要功能组的复用 |

表头应使用深色填充和白字。颜色图例必须包含功能组、色块、含义和适用字段。相同功能组在所有工作表中使用同一色值，不能按工作表重新随机配色。

## 排版设置

- 主视图启用自动筛选，并冻结首行；宽表可继续冻结引脚号或功能识别列。
- 只在表达明确层级时合并单元格，筛选区域内避免跨列合并。
- 长文本自动换行，列宽以能显示主要内容且不造成过度横向滚动为准。
- 详细引脚表按功能组整行着色；汇总表按外设组或功能组着色；需求表按对应功能组着色。
- 隐藏网格线，保留边框和分组留白，保证打印和屏幕查看都能识别层级。

## 验证清单

- 逐脚表包含完整引脚范围，未把未使用引脚静默删除。
- 每个总览记录都能定位到具体引脚和原理图网络。
- 同一 IO 未被错误分配到两个互斥的实际功能。
- 所有功能组都有图例，且总览、明细和辅助表颜色一致。
- 重新打开文件后工作表、筛选、冻结窗格、换行和颜色仍保持正确。
- 公式、外部链接和关键字段没有错误或意外空白。
