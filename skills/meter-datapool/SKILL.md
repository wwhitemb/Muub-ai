# 仪表全局数据池开发规范

## 适用范围
仅在任务涉及本项目仪表数据池、通信数据到 UI/业务的共享、里程/电池/故障域或跨线程数据一致性时启用。普通嵌入式项目、Qt Model/View 或通用全局变量设计不得自动套用本 Skill。

> 通用RT-Thread模式（线程模板、互斥锁封装、命名约定）见 `coding-rtthread-style` Skill。

## 触发场景
- 新增/修改仪表数据字段
- 通信数据解析后存储、UI数据读取
- 业务计算结果更新、告警状态同步
- 多任务数据并发读写优化
- 数据有效性、超时管理
- 数据池与存储层交互、持久化同步

## 核心执行规范

### 1. 数据池结构设计
1. 按业务域拆分数据结构体：车速里程域、电池域、故障域、系统配置域、通信状态域
2. 所有数据字段必须标注：来源（CAN/RS485/一线通/业务计算）、单位、有效范围、更新周期
3. 每个数据字段配套有效性标志位，数据异常、超时时标记为无效
4. 数据池结构体全局唯一，静态分配，禁止动态创建
5. 里程数据拆分存储：`odo_raw`（百位及以上，单位0.1km）+ `acc_dist`（十位及以下，单位m）

### 2. 读写接口规范
1. 禁止外部直接访问数据池结构体成员，必须通过封装的读写接口操作
2. 写接口：仅通信层、业务层调用，写入时自动加互斥锁保护，保证线程安全
3. 读接口：UI层、业务层、存储层均可调用，读取时加锁，避免数据撕裂
4. 批量读写提供原子操作接口，禁止多次单字段读写导致数据不一致
5. 使用局部变量临时存储读取的数据，避免持锁期间执行耗时操作

### 3. 数据有效性管理
1. 所有周期更新的数据必须带时间戳，记录最后一次更新时间
2. 超时未更新的数据自动标记为无效，UI层显示占位符，业务层触发告警
3. 写入数据必须做范围校验，超出合法范围的数据丢弃，不更新数据池
4. 关键数据保留上一帧有效值，异常时不覆盖正常数据
5. 里程数据范围限制：`km_int` 0~999999，`m_int` 0~999

### 4. 分层对接规则
1. 通信层：解析协议成功后，调用写接口更新对应字段，不做业务处理
2. 业务层：从数据池读取原始数据，计算后写回结果字段，不直接操作UI
3. UI层：仅从数据池读取显示数据，不修改数据池内容，不做业务计算
4. 存储层：从数据池读取需要持久化的数据，异步写入文件系统
5. 存储层读取模式：`mutex_take → 读取数据到局部变量 → mutex_release → 执行写文件操作`

### 5. 互斥锁使用规范
1. 每个数据域配备独立互斥锁，避免锁粒度过大导致阻塞
2. 禁止嵌套互斥锁，防止死锁
3. 互斥锁命名：`模块_mutex`，如 `can_history_mutex`、`user_io_mutex`
4. 锁的生命周期：模块初始化时创建，模块退出时销毁
5. 持锁时间最小化：仅在读取/写入共享数据期间持有锁

### 6. 存储层交互规范
1. 存储层通过事件组（`rt_event_t`）接收写入通知，不主动轮询数据池
2. 存储线程优先级低于通信线程和UI线程，避免抢占关键任务
3. 启动加载：存储模块初始化时读取文件 → 转换数据格式 → 通过写接口更新数据池
4. 运行时同步：存储模块响应事件 → 读取数据池 → 写入文件系统
5. 数据格式转换：文件存储格式（km_int + m_int）↔ 数据池格式（odo_raw + acc_dist）

### 7. 启动加载流程
1. 存储线程启动 → 读取文件 → CRC校验 → 数据有效性检查
2. 文件不存在：创建新文件，写入默认值（全0）
3. 文件校验失败：重置为默认值并写入文件
4. 数据转换：`odo_raw = km_int * 10 + (m_int / 100) % 10`，`acc_dist = m_int % 100`
5. 写入数据池：调用写接口更新里程数据，加互斥锁保护

## 输出要求
1. 新增数据字段必须说明：所属域、来源、单位、范围、更新周期
2. 读写接口必须说明线程安全性与调用层级限制
3. 涉及数据交互必须说明流向：从哪个模块写入、供哪些模块读取
4. 异常处理必须说明超时时间、无效值处理逻辑
5. 涉及存储层交互必须说明事件定义与互斥锁保护

## 代码示例

### 数据池里程域结构
```c
typedef struct {
    uint32_t odo_raw;   /* 里程百位及以上，单位0.1km */
    float acc_dist;     /* 里程十位及以下，单位m */
} history_distance_t;

extern history_distance_t g_history_distance;
```

### 互斥锁保护读取模式
```c
can_history_mutex_take();
odo_raw = g_history_distance.odo_raw;
acc_dist_f = g_history_distance.acc_dist;
can_history_mutex_release();
```

### 数据格式转换（文件→数据池）
```c
init_odo_raw = (km_int * 10) + ((m_int / 100) % 10);
init_acc_dist = (float)(m_int % 100);
```

### 数据格式转换（数据池→文件）
```c
total_m = odo_raw * 100 + (uint32_t)acc_dist_f % 100;
km_int = total_m / 1000;
m_int  = total_m % 1000;
```

### 互斥锁命名示例
```c
extern rt_mutex_t can_history_mutex;  /* CAN历史数据互斥锁 */
extern rt_mutex_t user_io_mutex;      /* UI输入变量互斥锁 */
```
